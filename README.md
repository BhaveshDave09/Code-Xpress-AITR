## 🎯 About the Challenge

Organized annually by the **Acropolis Institute of Technology and Research (AITR) ACM Student Chapter**, **100 Days of Code Xpress** is a consistency-driven coding sprint aimed at building rock-solid problem-solving habits, algorithmic thinking, and competitive programming skills.

### 📌 My Goals
- [x] Kickstart the challenge with **C++**
- [ ] Solve at least **1–2 algorithmic problems** every single day
- [ ] Master core **Data Structures & Algorithms** (Arrays, Strings, Recursion, STL, Trees, DP)
- [ ] Write clean, optimal, and well-commented code with Time & Space complexity notes
